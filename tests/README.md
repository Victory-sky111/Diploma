### **Дипломная работа**

# Описание проекта
В данной дипломной работе реализовано 2 проекта. 
Первый проект UI_test предназначен для проверки функционала вкладки Личные события сайта https://skyeng.ru/ при помощи автоматизированных UI тестов.
Второй проект test_api.py предназначен также для проверки функционала вкладки Личные события сайта https://skyeng.ru/, но уже при помощи API тестов и библиотеки Requests

# Запуск проектов

Для запуска первого проекта необходимо ввести команду:
pytest tests/UI_test/

Для запуска второго проекта необходимо ввести команду:
pytest tests/test_api.py


# Просмотр отчета

Для просмотра отчета необходимо ввести команду:

-m pytest --alluredir allure-result
